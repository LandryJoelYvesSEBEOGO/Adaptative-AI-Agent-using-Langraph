# Description YouTube - Système RAG avec Reranking

🤖 **Agent RAG Adaptatif avec LangGraph - Système de Question-Réponse Intelligent**

• **RAG (Retrieval-Augmented Generation)** : Système de question-réponse qui combine recherche vectorielle et génération de texte
• **LangGraph** : Orchestration adaptative du workflow de recherche et génération
• **Reranking** : Modèle CrossEncoder pour améliorer la pertinence des résultats
• **Base vectorielle ChromaDB** : Stockage et recherche rapide dans vos documents
• **Recherche web Tavily** : Accès aux informations récentes en temps réel
• **Groq API (LLaMA 3)** : Génération de réponses rapides et précises
• **Interface React moderne** : Frontend TypeScript avec authentification et dashboard admin complet
• **Dashboard Admin** : Vue d'ensemble avec métriques en temps réel (requêtes, taux de succès, latence, graphiques)
• **Métriques de performance** : Analyse détaillée des latences par composant (Retrieval, Generation, Grading)
• **Qualité des réponses** : Évaluation automatique (pertinence, complétude, précision, cohérence) avec graphiques radar
• **Gestion des requêtes API** : Historique complet avec filtres, recherche et export des données
• **Gestion des utilisateurs** : Administration des comptes, rôles et permissions
• **Paramètres système** : Configuration RAG, alertes, seuils de performance et maintenance
• **API FastAPI** : Backend robuste avec gestion d'erreurs et métriques
• **Recherche adaptative** : Décision automatique entre recherche locale et web
• **Système de retry intelligent** : Gestion automatique des erreurs et récupération

**Technologies** : Python, FastAPI, React, TypeScript, LangGraph, ChromaDB, Groq, Tavily, CrossEncoder
